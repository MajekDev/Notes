# Notes

Notes is a clientside Minecraft mod that provides a fully functional notepad in-game.

Downloads and more information can be found on [CurseForge](https://minecraft.curseforge.com/projects/notes) and [Modrinth](https://modrinth.com/mod/notes).

## About this fork

This is a modified version of [Notes by ChaosTheDude](https://github.com/MattCzyr/Notes) that adds note sharing for multiplayer servers:

- **Share with a player:** send a copy of a note to another player, even if they're offline. They can accept or decline it.
- **Shared server notes:** notes stored on the server that every player can see and edit, with changes shown live.

For sharing to work, install the mod on the server as well as on each client. Clients without it can still join, and without the server mod everything works like the original.
